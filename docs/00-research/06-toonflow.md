# 参考调研 · Toonflow（2026-11-13）

[Toonflow](https://github.com/HBAI-Ltd/Toonflow-app)（HBAI-Ltd，MIT 许可）是开源的「AI 短剧、漫剧与视频创作平台」，和本项目做的是同一件事：一块无限画布，接入自己的模型，从剧本到角色、分镜、视频片段。这份调研**下载了源码、在本机构建并实际运行**，逐项操作后与本项目对比，并据此确定 rc.20 的改进。

## 一、怎么试的

- 源码：GitHub `HBAI-Ltd/Toonflow-app`，提交 `6086cdf`（2026-11 最新）。许可：当前版本 MIT；README 说明 v1.0.8 之前是 AGPL-3.0、v1.0.8–v1.1.8 是 Apache-2.0 加附加协议——本项目只参考当前 MIT 版本。
- 技术栈：Bun 1.4.3、Vue 3 + Vue Flow、Electrobun 桌面壳、Element Plus；monorepo 里有 22 个包（节点、工具、技能、团队、供应商、MCP、多租户、ASR……）。
- 运行：在隔离目录 `bun install --frozen-lockfile`（969 个包，21 秒）→ `bun run build:server` → `bun run start:server`，服务在 3000 端口启动（426 ms）。用 Playwright 逐页操作并截图。
- 没有登录它的云端账号（Toonflow 官方模型平台），也没有配置付费模型：生成类功能只看界面与源码，本地功能（拆镜头、宫格切分、图片工具面板）实际跑通。

## 四、rc.20 采用了什么

1. **按模型的视频能力**：Seedance 2.0 4–15 秒、480p / 720p / 1080p、可生成声音、最多 9 张参考图；Seedance 2.5、MiniMax H3 最长 30 秒；其余模型保持 5 / 10 秒。时长、分辨率、「生成声音」随所选模型出现。数值取自 Toonflow 两家以上供应商定义一致的部分。
2. **拆镜头**：本机 FFmpeg 检测切换，每个镜头一张关键帧、一段片段，加原音轨，按种类分组放在视频旁边；视频节点和视频结果上都有按钮，MCP 也能调用（`split_shots`）。
3. **图片工具**：换角度（10 个机位预设 × 远中近 × 标准 / 广角）、重新打光（8 种光线风格 + 6 个主光方向 + 亮度 + 补充说明）——提示词构造改编自 Toonflow 的 `imageMultiAngle.ts` / `imageLighting.ts`（MIT，已登记）；宫格切分在浏览器里完成，不调用模型。
4. **OpenAI 兼容图片模型接受参考图**：Seedream 一类走 `image` 字段，gpt-image 一类走 `/images/edits`，档案里可指定。没有这一步，上面的图片工具在最常见的模型上用不了。
5. **导出 Skill**：设置 → Agent 接入里复制 / 下载 `SKILL.md`，放进 Claude Code 的技能目录，教它什么时候用画布、按什么顺序调用工具、先报费用再运行。

## 五、没有采用的，以及原因

- **3D 导演台**：依赖完整的 three.js 场景与人偶系统，体量接近一个独立产品；先用「换角度」解决最常见的机位需求。
- **局部重绘、全景图**：需要蒙版绘制或全景模型，且多数服务商的接口差异大；放到以后。
- **插件市场与可编辑的供应商代码**：在用户电脑上运行第三方代码需要沙箱和审核；本项目坚持「只用文字指令，不执行下载来的代码」。
- **内置 Agent 与 A2A 团队**：本项目的路线是让用户已有的 Agent（Claude Code 等）通过 MCP 操作画布，并保留付费前确认；画布助手负责应用内的轻量规划。
- **云端账号、作品社区、充值**：与「本地优先、自带 Key」的定位相反。
- **全能参考里的参考视频 / 参考音频**：Seedance 2.x 要求它们是公网 http(s) 地址，桌面版的本地文件无法直接提供；等有安全的临时外链方案再做。
- **21 种界面语言**：先保持中文界面与中英文文档；多语言需要完整的文案抽取，单独排期。
