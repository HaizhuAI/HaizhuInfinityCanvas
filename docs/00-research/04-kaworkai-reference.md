# 参考调研 · 咔作画布（kaworkai.com）

- 调研日期：2026-11-07（rc.4 之前）
- 方式：用浏览器以**未登录访客**身份打开首页与画布页，截图并读取界面文字与按钮名称。未登录、未付费、未调用其生成功能；画布页对访客弹出登录框，关闭后会回到首页，因此画布界面是在登录框后面观察的（只隐藏了本地页面上的登录遮罩，不涉及任何账号或数据）。
- 结论性质：**只借鉴交互思路**。没有复制其代码、文案、图片、图标或品牌；不引入其登录、点数计费、分享等与本地优先产品无关的部分。

## 观察到的画布结构

| 区域 | 内容 |
| --- | --- |
| 顶部（浮动的胶囊，而非整条顶栏） | 站内导航、项目名（双击改名）、最近项目切换、保存状态（「已保存到本机，未同步云端」）、浅色 / 深色切换；右侧分享、联系、点数余额、登录、「对话」 |
| 左侧浮动工具栏 | 图层管理、上传图片、素材库、风格库、提示词收藏、我的素材（品牌套件）、保存、新手引导 |
| 底部浮动工具栏 | 小地图开关、网格吸附开关、连线开关、整理、缩小 / 缩放比例 / 放大、恢复全景、快捷键 |
| 空画布 | 「双击画布 创建节点」引导、上传图片、从资产库导入、「也可以将本地图片拖入画布」 |
| 右侧对话面板（AI 助手） | 「说出你想要的图，我来挑工具、搭节点、出图」；新建对话、历史对话、设置、停靠 / 悬浮、收起；起步建议：读取当前画布开始创作、上传产品图做一套电商图、照着参考图做同款、搭一个 3D 场景出图 |
| 快捷键 | 复制 / 粘贴 / 全选 / 撤销 / 重做 / 保存（Ctrl S）/ 删除 / Esc 取消选择；滚轮缩放、Space 或鼠标中键拖动平移、左键拖空白处框选、方向键微移 1px（Shift 10px）、F 放大查看、Alt 拖拽复制 |
| 首页 | 一句话输入框（可加参考图、@ 引用素材、选创作类型 / 模型 / 比例与数量）、工具入口、特色工作流卡片（带示意图）、灵感搜索、项目管理、资产 |

## 与本项目的对照与取舍（rc.4）

| 借鉴的思路 | 本项目的做法 | 状态 |
| --- | --- | --- |
| 画布内 AI 助手：一句话挑工具、搭节点 | **画布助手**：用你自己的文本模型，把一句话变成节点方案（节点、连线、提示词都填好），**先给你看方案、确认后才加到画布**，可选加完立即运行；会读取当前画布，可在已有节点上接着搭 | rc.4 |
| 项目管理页 | **我的画布**：卡片网格（封面、节点数、更新时间）、搜索、打开 / 重命名 / 创建副本 / 导出项目包 / 删除 | rc.4（此前没有删除画布的入口） |
| 风格库、提示词收藏 | **提示词库**：内置风格词（本项目自己的写法）一点即加到选中节点；收藏常用提示词（反推结果可一键收藏）；拖到画布成为文本节点 | rc.4 |
| 底部工具栏的小地图 / 网格吸附开关 | 工具条加入两个开关，记住选择 | rc.4 |
| 快捷键：Ctrl S、Esc、方向键微移、F、Alt 拖拽复制、中键平移 | 全部加入，并写进快捷键面板 | rc.4 |
| 顶部浅色 / 深色切换 | 顶栏加一个主题切换按钮 | rc.4 |
| 新手引导 | 暂不做：空画布引导 + 运行前检查 + 快捷键面板已覆盖主要场景 | 不做 |
| 分享、点数、登录、品牌套件、图层任意缩放 | 与本地优先、节点工作流的定位不符 | 不做 |
