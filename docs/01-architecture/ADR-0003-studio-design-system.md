# ADR-0003 · 「工作室」设计系统（beta.5 起）

- 状态：**已采纳**（2026-11-05）。取代 [ADR-0002](./ADR-0002-ui-design-system.md) 中的配色、布局与「星空为唯一效果」部分；ADR-0002 的动效规则（GSAP 只在 `motion.ts`、只在状态变化时出现）继续有效。
- 参考：UI-UX-Pro-Max（MIT，设计知识库；只参考规则与档案，未复制代码或数据）

## 背景

beta.4 的「Deep Field」界面有辨识度，但主要用户是**图片和视频创作者**：他们在画布上看的是自己的作品。深蓝底色和青绿强调色会让画面偏色，星空背景与作品抢注意力，节点里塞满参数，媒体反而很小。用户反馈「还不够满意」，要求参考 UI-UX-Pro-Max 做高端软件质感。

UI-UX-Pro-Max 按产品类型给出风格与规则。与本项目最接近的四个档案是：生成艺术平台（88）、照片编辑（126）、短视频编辑（127）、绘画画布（128）。四者的共同结论：**内容优先、中性背景、一个强调色、工具退后**。

## 决策

1. **中性深灰，不带色偏**：背景 `#0b0b0c`、面板 `#141416`、表面 `#19191c` / `#212125`；浅色主题对应 `#e9e9ec` / `#fafafa` / `#ffffff`。作品颜色在两种主题下都不失真。
2. **唯一强调色：粉色 `#EC4899`**，按钮上的文字用近黑 `#0a0a0a`（对比度 6:1）。数据类型（文本 / 图片 / 视频 / 音频 / 分镜 / 文件）只用于端口和连线的小色点，不用于大面积。
3. **字体**：Inter（UI-UX-Pro-Max 字体搭配 #60「Modern Dark Cinema」）+ Geist Mono（数字、版本号），全部随包打包，离线可用；中文回退到系统字体。
4. **布局**：顶栏（品牌 · 居中画布名与菜单 · 运行）、图标导航栏、左侧面板（组件库 / 素材库）、画布、**常驻**属性面板。选中节点时面板内容切换，但布局不跳动。
5. **节点以内容为主**：媒体铺满节点宽度；未生成时显示按画面比例的结果框（生成中有微光）；节点里只留模型标签和一键运行，所有参数放进属性面板。
6. **效果克制**：星空背景改为可选、默认关闭（评估色彩时不干扰）；动效可整体关闭，系统「减少动态效果」时自动关闭。
7. **可读与可达**：两种主题下所有文字令牌对比度 ≥ 4.5:1（注释写在 `styles.css` 令牌旁）；图标按钮都有可读名称，装饰图标 `aria-hidden`；可见焦点环；组件库可用键盘添加；打开画布时缩放不低于 60%。
8. **检查方式**（对应 UI-UX-Pro-Max 交付前清单）：真实浏览器截图检查 1440 / 1600 / 1840 宽度、深色与浅色；五套 E2E 覆盖全部交互；新增界面（交付文件卡片、项目包菜单）沿用同一组令牌，不新增颜色。

## 后果

- 正面：作品成为视觉中心；界面在长时间创作中不疲劳；新功能只需复用令牌与组件（按钮、字段、分段选择、开关、文件卡片）。
- 负面：中性灰的辨识度低于 beta.4，品牌感主要靠粉色强调与图标；浅色主题下大面积白色媒体（如纯白画面）与卡片边界较弱，靠细线边框和阴影区分。
- 迁移：ADR-0002 的 Galaxy 片段（轨道加载器、流动边框、开关）保留，已改用本设计系统的令牌。
