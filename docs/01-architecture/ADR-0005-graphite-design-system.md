# ADR-0005 · 「石墨」设计系统：去掉 AI 感（rc.11 起）

- 状态：**已采纳**（2026-11-12）。取代 [ADR-0003](./ADR-0003-studio-design-system.md) 的配色、字体与圆角；ADR-0003 的布局（顶栏 / 图标栏 / 左侧面板 / 画布 / 常驻属性面板）与「节点以内容为主」继续有效；ADR-0002 的 GSAP 规则（只在 `motion.ts`、只在状态变化时出现）继续有效。
- 参考：用户提供的 Galaxy（uiverse.io 开源组件库，MIT）、Taste Skill（反模板化前端准则，MIT）、UI-UX-Pro-Max（MIT）。

## 背景

用户反馈界面「有 AI 感」，要求用他提供的组件重新设计。对照 Taste Skill 的检查项，rc.10 界面的问题集中在几处常见的「AI 生成」特征：

| 特征 | rc.10 的位置 |
| --- | --- |
| 发光的饱和强调色（粉色按钮带同色光晕阴影）、渐变 Logo 方块 | 主按钮、品牌标志 |
| 每个图标都放在一个着色的圆角方块里 | 组件库、模板卡片、节点标题、面板 |
| 等宽字体、字距拉开的大写小标签放在大标题上方（eyebrow） | 空画布、首页、属性面板分组 |
| 闪光图标 ✨ 代表「智能」 | 助手按钮、提示、Skill 标签 |
| 胶囊状态徽章、渐变文字、光晕背景、毛玻璃、星空背景 | 节点状态、首页、浮动工具条、可选背景 |
| 居中大标题 + 标签行 + 编号步骤 + 三列卡片的首页模板；破折号句式 | 首页 |

## 决策

1. **颜色**：界面 90–95% 中性，只有一个强调色。深色取 Taste Skill 调色板「Graphite and orange」：底色 `#161719`、画布 `#131416`、面板 `#1b1c1f`、表面 `#212226`，文字 `#eff0f1`，次要文字 `#9c9ea3`；浅色为冷灰 `#e8e9ea` / `#f7f7f8` / `#ffffff`，文字 `#18191b`。**强调色 `#ff4a1f`（信号橙）只用于**：主按钮、焦点环、选中的节点、运行中的进度条、开关开启。按钮上的字用近黑 `#18191b`（5.2:1）。选中态的分段选择、标签页、筛选用墨色（文字色），不用强调色。数据类型颜色只出现在端口点和连线上，并避开橙色（视频改为琥珀色、分镜改为浅灰）。
2. **形状与层次**：圆角 4 / 6 / 8；平面表面 + 1px 细线；不用发光阴影、渐变填充、毛玻璃；弹窗遮罩不模糊；悬浮工具条、顶栏都是不透明的。
3. **字体**：Geist（正文）+ Geist Mono（数字、版本、代码）；移除 Inter。标签一律句首大写的常规写法、12px 起，不用字距拉开的大写。
4. **图标**：不再放在着色方块里，直接用文字色线条图标；节点标题图标保留类型色（画布上辨认节点用）。助手用对话图标，Skill 用卷轴图标，不再用闪光图标。
5. **组件**（从 Galaxy 挑选后用本项目令牌重写，来源逐条登记在 THIRD_PARTY_NOTICES）：分段选择（andrew-demchenk0）、开关（The-Best-Codes）、下划线链接（MuhammadHasann）、提示标签（SouravBandyopadhyay）、底部图标工具条（csemszepp）、细进度条（SteveBloX，节点运行时的顶边进度）、刻度加载器（elijahgummer）、复选框（IndexOC）、画布网格（adamgiebl，细线网格 + 每 5 格一条稍深的线，取代点阵）。只挑了没有渐变、发光、霓虹、拟物、3D 的组件——Galaxy 里大部分组件风格互不一致，整体照搬会破坏「一套系统」。
6. **状态**：节点状态改为「彩色小图标 + 文字」，不再用胶囊底色；运行中是节点顶边的一条进度线；选中是 1px 强调色描边加外描边，不再有光晕。
7. **动效**（Taste Skill 的数值）：按钮悬停上移 1px、按下下沉 1px 并缩到 0.985；可点击的卡片悬停上移 2px；下划线从左向右画出；不倾斜、不发光、不随滚动淡入。去掉星空背景（与作品争夺注意力）。
8. **品牌标志**：「海柱」——一根柱子立在海上：橙色柱体 + 两道墨色波线；应用图标是平面石墨底色方块，不用渐变。
9. **首页**按 Taste Skill 的软件页规则重写：首屏只有主视觉——标题直接说「给图片和视频创作者的节点画布」，下面一句说明 + 一条硬事实（支持的接口与平台），两颗按钮，然后是真实的产品截图大幅展示并延伸出首屏；顶栏不透明带细线；之后每节一个标题、真实截图；不用小标签、标签行、编号步骤、渐变字、光晕；首页文字用 Taste Skill 的 copy-lint 检查（0 失败 0 警告；该工具按英文词表统计，中文部分人工按其规则复查：无破折号、无「X。Y。」式空洞标题、无「强大 / 无缝 / 一站式」类词）。登录 / 注册页沿用首页的按钮与卡片。

## 后果

- 正面：界面像一个专业的创作工具，作品是屏幕上唯一大面积的颜色；新界面只需复用令牌与组件。
- 负面：数据类型颜色在组件库里不再出现（只在端口与连线上），靠分组标题区分；首页的「一屏一节」在内容较少的节改为自然高度——Taste Skill 的「不留半屏空白」优先。
- 检查方式：13 套 E2E、截图脚本（22 张）在深色与浅色下逐张检查；首页在 1440 / 1024 / 390 宽度截图检查。
