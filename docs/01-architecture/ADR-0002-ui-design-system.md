# ADR-0002 · 界面设计系统与动效（beta.4）

- 状态：**已采纳**（2026-11-05）
- 参考：GSAP（动效库）、Galaxy / uiverse.io（开源 UI 片段库）、Taste Skill（前端设计准则）

## 背景

beta.3 的界面功能完整但「像模板」。用户要求参考 GSAP、Galaxy 与 Taste Skill 做沉浸式重做。三者性质不同：GSAP 是动效引擎，Galaxy 是风格各异的社区片段库，Taste Skill 是一套「反模板化」的设计规则（主要面向官网，但其系统性规则适用于应用）。

## 决策

1. **一套系统（Taste Skill）**：一套圆角（6 / 10 / 14）、一对按钮（浅色实心主按钮 + 次按钮，停止用红色）、一种卡片（节点）、一套标题字号；界面里不用紫色（原紫色强调色与 Logo 渐变全部替换为青绿 / 天蓝）。
2. **一个效果（Taste Skill 对「技术类产品」的规定）**：全窗口星空背景是唯一的「效果」。Canvas 2D 绘制、约 30 fps、标签页隐藏时暂停、随画布平移轻微视差；系统开启「减少动态效果」或在设置里关闭动效时变为静态。顶栏、侧边栏为半透明毛玻璃。
3. **动效克制（Taste Skill + GSAP）**：只在状态变化时出现——节点出现（同一帧出现的节点依次进入）、弹窗/菜单/提示出现、节点完成时的一圈成功光晕；按钮悬停上移 1px、按下缩小；不倾斜，不做滚动触发动画。所有 GSAP 调用集中在 `motion.ts`。
4. **Galaxy 只取适合的片段并改写**：数千个片段风格互不一致，整体照搬会破坏「一套系统」。只取 3 个并改写为本项目的颜色令牌：运行中的多色边框（停止按钮）、三弧轨道加载器（运行状态）、开关（外观设置）。来源与改动登记在 THIRD_PARTY_NOTICES。
5. **字体离线可用**：Geist / Geist Mono 随包打包（OFL-1.1），中文回退到系统字体（苹方 / 微软雅黑）。
6. **检查方式**：真实浏览器截图检查 1440、1024 宽度，深色与浅色两种模式；四套 E2E 覆盖所有交互。

## 后果

- 正面：界面统一、有辨识度；动效可整体关闭；GSAP 可在一个文件内替换。
- 负面：毛玻璃（backdrop-filter）在低端显卡上有一定开销——已提供「关闭动效」开关；GSAP 许可证不是开源许可，使用边界见许可证审计。
