# 使用指南 · 短剧工坊（rc.19 起）

[shuohao-skills](https://github.com/eternityspring/shuohao-skills)（作者 烁皓，Apache-2.0）是一套在 Claude Code 里把小说改编成 AI 短剧的 Skill：大纲 → 角色 → 美术 → 剧本 → 分镜，产出一组 JSON 文件，以及按 Seedance / MiniMax H3 官方写法拼好的视频提示词。

画布从它那里吸收了四样东西，并且能直接读它的产出：

| 来自 shuohao-skills | 在画布上 |
| --- | --- |
| character-refs：先出一张锚点，其余视图只参考锚点 | 主体节点的**生成参考图组** |
| novel-storyboard 的 Seedance / H3 写法与镜头写法 | 「优化提示词」的 Seedance、MiniMax H3 规则；内置导演 Skill **短剧分镜（shuohao）** |
| 输出的 outline / cast / art / script / storyboard JSON | **导入短剧工程**：一次变成主体、分组、分镜图、视频和导出节点 |
| 每个镜头的负面词 | 图片 / 视频生成节点的**负面词**参数 |

## 一、主体参考图组（角色设定图）

1. 拖出一个**主体**节点，写名字（如 `沈知微`），选人物 / 物品 / 场景，写一段外观描述。
2. 在节点底部选画风（**动漫** / **写实照片**），点**生成参考图组**。
3. 画布在主体右边放一个分组，里面是这一组的图片生成节点，并且**只运行第一张（锚点）**：

   | 主体类型 | 锚点 | 其余视图（只参考锚点） |
   | --- | --- | --- |
   | 人物 | 正面全身（3:4） | 大头照、侧面全身、背面全身 |
   | 物品 | 正面（1:1） | 侧面、细节特写 |
   | 场景 | 一张没有人物的全景（16:9） | — |

4. 运行结束时提示「**出其余视图**」。满意就点它；不满意就在锚点节点上再出一版，换了锚点再出其余视图。其余视图不互相参考，偏差不会一张张累积。
5. 每张出完**自动放进主体**，按视图顺序排列，最多 4 张；你自己加的图保留在后面。某个视图再出一版，会替换它原来那张。之后在任何提示词里写 `@沈知微`，支持参考图的模型就会收到这些图。

提示词固定了纯白背景、中性站姿、不加文字和水印；负面词写在每个节点的「负面词」里，都可以直接改。画风只改「怎么画」，不改人物是谁。出其余视图需要支持参考图的图片模型（Replicate / fal、可灵、Runway 等，见[画布操作](./canvas-basics.md)）。

## 二、导入 shuohao-skills 的短剧工程

**入口**：按 `/` 搜「短剧」，或在画布空白处右键 →「导入短剧工程（shuohao-skills）…」，一次选中多个 JSON 文件。

每个文件按**内容**识别（文件名无所谓），缺哪个都能导入，能放多少放多少：

| 文件 | 变成什么 |
| --- | --- |
| cast（角色） | 人物主体，描述取角色的画面提示词（没有时取大纲里的人设） |
| art（美术） | 场景、物品主体 |
| outline（大纲） | 补齐名字；没有 cast / art 时也能建主体 |
| storyboard（分镜） | 每一**段**一个分组（段号 · 场景）；段里每一**切**一个图片生成节点（分镜图，提示词里的角色名写成 `@名字`）；每一段一个视频生成节点；最后一个导出节点 |
| script（剧本） | 台词：逐字写进对应镜头的 `台词：{…}` |

视频生成节点：

- **时长** = 这一段各切秒数之和（Seedance 2 一段最长 15 秒）。
- 一段有多切时，分镜图依次接到「参考图」端口，提示词开头写 `@[图片1] = 分镜图 #1`……，每切的画面写「构图参考 @图片k」；只有一切时接到「首帧」。
- 提示词按 **Seedance 官方结构**合成：人物关系与构图逻辑 →【镜头k】（焦距、机位、构图、运镜、景别、画面、台词 `{}`、视线落点、焦点、稳定性、音效）→ 环境声 `<>` → 配乐 `（）` →【约束】（无字幕；两人及以上同框时不出现外形完全一致的人物）。
- 第一个视频模型档案是 **MiniMax H3**（模型名含 H3）时，改用文件里自带的 H3 提示词。

导入的内容放在已有节点的右边，自动绑定你的第一个图片 / 视频模型档案；画布上已有同名主体时不会重复创建；一次最多导入 60 段，超出时会提示。导入不会运行任何东西。

**推荐的顺序**：给主要角色和场景**生成参考图组** → 运行各段的分镜图（分组标题栏的「运行」）→ 满意后运行视频 → 在导出节点的时间线里检查顺序 → 导出成片。

## 三、短剧分镜导演 Skill

导演节点的 Skill 里选**短剧分镜（shuohao）**：把一段剧本或小说拆成能直接投产的分镜——每个镜头是一段视频生成（不超过 15 秒），段内每 2–5 秒一切；首帧提示词直呼 `@角色`；视频提示词按上面的 Seedance 结构写，台词逐字保留。它的参考文件（镜头写法、Seedance 写法、H3 写法）原样照录自 shuohao-skills，随 Skill 一起交给模型。

自己写的导演 Skill 也可以用 `metadata.hzc-max-duration` 设置单个镜头的最长秒数（见[导演 Skill](./director-skills.md)）。

## 四、和 Claude Code 一起用

画布接入 Claude Code 以后（见 [Agent 接入](./agent-mcp.md)），可以让 Claude Code 先用 shuohao-skills 做完改编，再把整个工程交给画布：

> 「用 shuohao-skills 把 novel.txt 做成分镜，然后把整个工程导入海柱画布的新画布。」

Agent 用 `import_drama` 工具导入：传 JSON 内容，或者（桌面版 / 本机服务）传文件的绝对路径。shuohao-skills 需要按它自己仓库的说明安装到 Claude Code。

## 五、没有搬过来的部分

- 原 Skill 用 Python 脚本完成切段对账、校验、提示词拼接和 HTML 报告。画布不运行任何下载来的脚本：拼接由画布自己的代码完成，结果直接显示在节点上，校验交给运行前检查。
- 原 Skill 的分阶段工作目录与审批流程：在画布上，这些阶段就是你看得见、能改的节点。
