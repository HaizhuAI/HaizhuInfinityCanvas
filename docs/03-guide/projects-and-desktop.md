# 使用指南 · 项目包、桌面版与部署

## 项目包（.hzc）：备份、换电脑、分享

画布名称旁的菜单里有两种导出：

| 导出 | 包含 | 适合 |
| --- | --- | --- |
| **导出项目包**（`.hzc`） | 画布、所有用到的素材（图片 / 视频 / 音频 / 成片 / 剪辑工程）、全部生成结果 | 备份、换电脑、把完整项目交给同事 |
| **仅导出画布结构**（`.json`） | 节点、连线、参数和提示词，不含素材与结果 | 当模板分享 |

「导入项目包或画布文件…」两种都能打开（按文件内容自动识别），导入后会新建一个名称带「（导入）」的画布，原画布不受影响。

- 导回**同一台电脑**：素材不会重复保存，缓存仍然有效，「运行全部」不会重复调用模型、不会重复扣费。
- 导入**另一台电脑**：素材和结果都会显示；模型档案（含 API Key）**不会**随项目包带走——在新电脑上配置好同名或同类模型档案，再在节点上重新选择即可。重新选择模型后，相关节点需要重新运行。
- 项目包本身是一个 zip 文件，最大 4 GB；导入时单次上传上限 2 GB。

## 桌面版

- 数据保存在本机：Windows `%APPDATA%\HaizhuInfinityCanvas\data`，Linux `~/.config/HaizhuInfinityCanvas/data`（画布数据库、素材、Skill）。备份可以直接复制这个文件夹，或者逐个导出项目包。
- 应用内置服务只监听本机回环地址，每次启动使用随机端口和随机访问令牌。
- **API Key 的保护**：Key 用 AES-256-GCM 加密后存进数据库，浏览器界面永远拿不到明文。加密用的密钥：
  - Windows：交给系统钥匙串（DPAPI）保管，只有当前 Windows 用户能解开；
  - Linux：有钥匙串服务（GNOME Keyring / KWallet）时交给它保管；没有时保存在数据目录中权限为 0600 的 `master.key` 文件里。
  - 从旧版本升级时，原来的 `master.key` 会自动移入钥匙串并删除明文文件，已保存的 Key 照常可用。
  - 如果某次启动时钥匙串打不开（例如更换了系统用户或桌面环境），应用会询问：**退出**（恢复钥匙串后再打开，Key 不丢）或**重置已保存的 API Key 并继续**（画布、素材、结果都保留，Key 需要重新填写）。原来的封存文件会改名保留，不会删除。
- 复制数据文件夹到另一台电脑时，已保存的 API Key 无法解密（这是预期的保护）。运行时会提示「请在设置 → 模型档案里重新填写 Key」。
- FFmpeg 需要另行安装，见[视频反推与导出](./video-and-export.md)。

## WebUI / Docker 部署

```bash
cp .env.example .env     # 设置 HZC_TOKEN（必填，非回环地址监听时没有令牌会拒绝启动）
docker compose up -d --build
```

| 环境变量 | 说明 |
| --- | --- |
| `HZC_TOKEN` | 访问令牌。浏览器首次打开 `http://主机:8787/?token=…` 后会记住它 |
| `HZC_HOST` / `PORT` | 监听地址与端口（Docker 默认 `0.0.0.0:8787`） |
| `HZC_DATA_DIR` | 数据目录（Docker 卷） |
| `HZC_MASTER_KEY` | 可选：64 位十六进制的加密密钥（例如来自密钥管理服务）。设置后不再读写 `master.key` 文件；更换它会使已保存的 API Key 无法解密 |
| `HZC_FFMPEG` / `HZC_FFPROBE` | 可选：FFmpeg 可执行文件路径 |

访问令牌只在请求头里有效；素材和项目包的下载链接可以带 `?t=令牌`（因为 `<img>`、`<video>` 和下载链接无法发送请求头），其余接口不接受网址里的令牌。

## 隐私与网络

- 应用本身不收集任何数据，不检查更新，不连接除你配置的模型服务以外的地址。
- 提示词、图片和视频只发送给你在模型档案里配置的服务商；错误信息里出现的 API Key 会被打码。
