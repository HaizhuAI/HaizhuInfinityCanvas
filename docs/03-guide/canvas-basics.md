# 使用指南 · 画布操作、画布助手、多模型对比、快捷键与运行前检查

## 添加节点

| 方式 | 说明 |
| --- | --- |
| 左侧组件库 | 拖到画布上，或单击 / 回车添加到视图中央的空位 |
| `/` 或双击空白处 | 打开快速添加面板，可搜索节点、模型、导演 Skill 和模板 |
| 右键空白处 →「在这里添加节点…」 | 在鼠标位置添加 |
| 从电脑拖入文件 | 图片、视频、音频直接拖到画布上，每个文件变成一个素材节点 |
| 粘贴（`Ctrl/⌘ V`） | 剪贴板里有截图或图片时，粘贴为图片节点；否则粘贴复制的节点 |
| 从连线添加 | 从一个端口拉出连线，松开在空白处：只列出能接上的节点，选中后自动连好 |
| 从结果拖出 | 鼠标停在节点的图片 / 视频上，拖动右上角的 ⠿：放到空白处成为新的素材节点，放到另一个同类素材节点上则替换它的文件 |
| 模板 | 空画布上四个常用模板（文生图 → 图生视频、创意 → 导演分镜、视频 → 镜头反推、图片 → 提示词反推），`/` 里还有「台词 → 配音」「创意 → 文本模型润色」 |

带模型的节点（文本、视觉、图片、视频、语音、导演、反推）会自动选用这一类上一次用过的模型，没有用过就用第一个。

## 结果版本（rc.3 起）

每次生成的结果都会保留（每个节点最近 30 版），不怕「重新生成」覆盖掉满意的那一版：

- 节点上的 **‹ 2 / 5 ›** 逐版切换；属性面板的「全部版本」以缩略图列出所有版本，点一下切换。
- 双击图片 / 视频全屏预览时，用 **← / →** 浏览各版本，「使用这一版」切换。
- 切换后的版本就是这个节点的当前结果：会保存（重新打开画布仍是它），下游节点下次运行时直接使用它，不会重新调用模型。
- 重新生成时，当前结果会继续显示（变暗并提示「重新生成中…」）；如果这次生成失败或被停止，原来的结果保持不变。
- 结果相同的生成不会重复记录。项目包（.hzc）只带当前版本。

## 画布助手（rc.4 起）

不知道该拖哪些节点时，点顶栏的「助手」（或右侧面板的「助手」标签），用一句话说出想做的东西，例如「做一张咖啡店秋季新品海报，再把它做成 5 秒的推镜头视频」。

1. 在面板顶部选一个文本模型（用你在「设置 → 模型档案」里配置的，请求只发给它）。
2. 助手回复一张**方案卡片**：要加哪些节点、各自的用途和写好的提示词、几条连线。此时画布上还什么都没加。
3. 点「添加到画布」加上这些节点（已连好线、已选好对应类型的模型），或「添加并运行」加完立即运行它们。加完可以撤销。
4. 可以接着说「给它配个音」「改成竖屏」：助手看得到当前画布和之前的对话，会把新节点接到已有节点上。

- 方案会先经过检查：不存在的节点、接不上的端口、一个只收一条线的端口上的第二条线、不认识的参数都会被去掉，卡片里的「已自动修正 N 处」列出原因。一次最多 16 个节点。
- 方案用到你还没有配置的模型类型时，助手会提醒你先去添加。
- 发给模型的内容：节点类型和名称、文本节点的前 80 个字、连线、最近 8 轮对话和你的新消息；**不发送图片、视频和 API Key**。
- 对话按画布保存在本机浏览器里；「新对话」（面板右上角）清空。
- 方案质量取决于所选模型，能稳定输出 JSON 的模型效果更好；模型只回答问题、没有给方案时，就只显示回答。

## 多模型对比（rc.5 起）

同一段提示词，哪个模型出得最好？不用手动复制节点、换模型、再一张张切换着看：

1. 右键一个模型节点（图片 / 视频生成、文本、视觉、语音、导演、反推），选「多模型对比…」；或在属性面板「模型」一栏点同名按钮。
2. 勾选要比较的其他模型（必须是同一类，当前模型固定在内，一次最多 4 个）。同类模型不到两个时，窗口里可以直接去添加。
3. 「添加并运行」：每个模型得到一个对比节点，提示词、参数和输入连线都和原节点一样，排在原节点下方，标着「对比 A / 3」「对比 B / 3」…；运行前照常会有运行前检查和费用确认。只想先摆好再运行，就点「添加到画布」。
4. 点任意一个对比节点上的「并排查看」：每个模型一栏，显示模型名、用时、单价和结果；有视频时「从头同时播放」可以同步比较动作和节奏。
5. 「选用这个」（或节点上的「选用」）：留下的那个移到原节点的位置，接管原节点通往下游的连线，其余对比节点移除；可以撤销。下游节点直接用留下的结果，不会重新生成。

- 不在同一组对比里的结果也能比较：选中 2–4 个有结果的节点，右键「并排比较」。
- 复制、粘贴、创建副本得到的节点不会加入原来的对比。手动删掉其他对比节点后，剩下的那个会显示「对比已结束」，点「收起」即可。

## 大画布

几百个节点的画布也能流畅拖动、平移和输入（rc.5 在 300 个节点上测过，见 CHANGELOG）。缩小到 40% 以下时，节点里看不清的文字和控件不再绘制，节点按类别着色（文本、模型、创作工具……），整张画布像一张地图；放大回来即恢复。

## 我的画布与提示词库（rc.4 起）

- **我的画布**（左侧栏最上方）：所有画布以卡片列出，封面是最近生成的图片（还没有生成时用素材图），显示节点数和更新时间。可以搜索、打开、重命名、创建副本（连同已生成的结果）、导出项目包、删除（需要确认；会一并删除它的结果、版本和助手对话；正在运行的画布要先停止）。
- **提示词库**（左侧栏）：
  - 内置风格词分四组：影像、插画与动画、3D 与产品、运镜（视频）。先选中一个节点，再点风格词即可加到它的提示词末尾；如果这个节点的提示词是从上游文本节点连进来的，会加到那个文本节点上；如果来自其他节点的输出（例如文本模型的结果），会提示你到那里修改。
  - 「我的收藏」：保存常用提示词；文本结果（例如提示词反推的结果）上的 ☆ 一键收藏。
  - 任何一条都可以拖到画布上，成为一个文本节点。

## 视图

- 画布下方工具条：小地图、网格吸附（24 px）两个开关，会记住你的选择；撤销 / 重做、适应画布、整理画布。
- 顶栏的太阳 / 月亮图标切换浅色与深色主题。
- 平移：拖动空白处或按住鼠标中键拖动；缩放：`Ctrl/⌘` + 滚轮；`Shift 1` 适应画布，`F` 放大查看选中的节点。

## 编辑

- **撤销 / 重做**：`Ctrl/⌘ Z`、`Ctrl/⌘ Shift Z`（或 `Ctrl Y`），也可用画布下方工具条的两个箭头。添加、删除、粘贴、连线各算一步；一次拖动、一段连续输入合成一步。每个画布单独记录，最多 100 步。
- **复制 / 粘贴 / 创建副本**：`Ctrl/⌘ C` / `V` / `D`。会带上选中节点之间的连线，以及提示词、参数和所选模型；不会带上运行结果。复制的内容可以粘贴到另一个画布。
- **右键菜单**：节点上——运行到这里、创建副本、复制、删除；空白处——添加节点、粘贴到这里、全选、适应画布、整理画布、撤销。
- **整理画布**：工具条上的 ▦（或右键空白处）。按连线从左到右排成几列，同一列尽量按上游的顺序排列，减少交叉；可以撤销。
- **查找节点**：按 `/` 输入名字或文本里的内容，「画布上的节点」一组里选中即可跳过去。
- **全选**：`Ctrl/⌘ A`；**框选**：按住 `Shift` 拖动；**多选**：`Ctrl/⌘` 点击。
- **微移**：方向键把选中的节点移动 1 px，`Shift` + 方向键 10 px；开启网格吸附时每次移动一格。连续微移合成一步撤销。
- **拖动复制**：按住 `Alt` 拖动节点，原位置留下一份副本（连同它们之间的连线）。
- **取消选择**：`Esc`；**保存**：`Ctrl/⌘ S`（平时也会自动保存）。
- **删除**：`Delete` / `Backspace`。

在文本框里输入时，`Ctrl/⌘ Z`、`C`、`V` 照常作用于文字，不会影响节点。

## 运行前检查

点「运行全部」（或 `Ctrl/⌘ Enter`）、节点上的 ▶ 时，会先检查这次要运行的节点，发现一定会失败的情况就先告诉你，而不是调用模型后再报错：

| 问题 | 在检查窗口里的处理 |
| --- | --- |
| 节点还没有选择模型（或之前选的已被删除） | 同一类的节点合成一行：有可用模型时直接「全部使用…」选一个；还没有这一类模型时「添加…」打开对应表单，保存后这些节点自动用上 |
| 素材节点还没有上传文件 | 「定位」跳到这个节点 |
| 没有连接输入，或连接的文本节点是空的 | 「定位」跳到这个节点 |
| 视频反推 / 导出成片需要 FFmpeg 但电脑上没有 | 「安装方法」 |

问题处理完，按钮变成「开始运行」；也可以直接「仍然运行」，先运行其余没有问题的部分。有付费的生成调用时，之后还会弹出费用确认。

## 同时运行（rc.7 起）

互不依赖的节点会同时运行：分镜展开后的各个镜头、多模型对比的各个模型都不用排队等前一个。顶栏会显示「同时 N 个」，还没轮到的节点显示「排队中」。

- 所有模型合计最多同时 4 个；每个模型最多 3 个。服务商提示请求过于频繁（429）时，到「设置 → 模型档案 → 编辑 → 高级设置 → 同时运行」把这个模型调成 1 或 2；额度充足可以调大（最多 8）。
- 本机模型（Ollama）同一台服务器一次只运行 1 个；导出成片一次 1 个。
- 某个节点失败时，只有依赖它的下游节点被跳过，其他分支继续完成。

## 出错时

- 节点里的红色提示说明原因，能直接修复的会带一个按钮：「选择模型」「添加…模型」「检查模型档案」（Key 无效或无权限）、「查看安装方法」（FFmpeg）。
- 运行结束时顶部提示失败的节点，点「查看原因」会选中并居中显示它。
- 修改出错的节点（上传文件、选择模型、改提示词）后，旧的错误提示会立即消失。
