# 使用指南 · 视频反推、导出成片与剪辑工程

## 准备：安装 FFmpeg

视频提示词反推和导出成片需要 FFmpeg。应用**不内置** FFmpeg，会自动查找系统里的 `ffmpeg` / `ffprobe`：

| 系统 | 安装 |
| --- | --- |
| Windows | `winget install ffmpeg`（或从 ffmpeg.org 下载后把 `bin` 目录加入 PATH） |
| Ubuntu / Debian | `sudo apt install ffmpeg` |
| Docker（WebUI） | 镜像里已安装 |

装在别处时，设置环境变量 `HZC_FFMPEG`、`HZC_FFPROBE` 指向两个可执行文件，然后重启应用。打开「设置 → 关于」可以看到是否找到了 FFmpeg、版本号，以及是否支持 H.264 / AAC 编码。

## 拆镜头：把参考视频拆成素材（rc.20 起）

鼠标移到任意视频（上传的视频或生成结果）上，点右上角的剪刀「拆镜头」：

- 检测画面切换，把视频拆成每个镜头，放在视频旁边的三个分组里：**关键帧**（每个镜头中间的一帧，S01、S02…，标着起止时间）、**镜头片段**（每个镜头单独一段视频，M01、M02…，保留声音）、**原音轨**（整段声音，m4a）。
- 全部在本机用 FFmpeg 完成，不调用模型，不花钱。镜头最多 60 个；切点太多时最短的相邻镜头会合并，没有切点的长镜头按约 5 秒均分。
- 拆出来的都是普通素材节点：关键帧可以连到「首帧」「参考图」，片段可以接到导出节点的时间线，原音轨可以作为配音参考。
- 要让模型描述每个镜头、写出提示词，用下面的「视频提示词反推」。Agent 可以用 MCP 工具 `split_shots` 做同样的事。

## 视频提示词反推：把一段视频拆成镜头表

1. 空画布上点「视频 → 镜头反推」模板，或从组件库拖入「视频」和「视频提示词反推」并连线。
2. 在视频节点上传或拖入一段视频（mp4 / webm / mov）。
3. 选中反推节点，在属性面板选择**视觉分析**模型档案，按需调整：
   - **最多镜头**：4–12 个。切点更多时，最短的相邻镜头会被合并。
   - **切镜灵敏度**：高 = 更多镜头，低 = 只在明显换镜时切分。没有切点的长镜头会按约 5 秒均分。
   - **提示词语言**：中文或英文（其余字段固定为中文）。
4. 运行。流程是：检测画面切换 → 分段 → 每个镜头取一张关键帧 → 一次性把全部关键帧按顺序交给视觉模型 → 得到分镜。镜头数量、时长、关键帧都来自视频本身，模型只负责描述。
5. 节点里显示带缩略图的镜头列表；第二个输出端口是可直接复制的提示词文本。

### 复刻：展开到画布

点「展开到画布」，每个镜头变成一行：**原关键帧（图片）→ 图片生成（关键帧作参考图）→ 视频生成（以生成的图为首帧）**，提示词已填好。末尾会自动加一个**导出成片**节点和一个字幕节点，并连好全部镜头。选好模型后「运行全部」即可得到复刻成片。

## 导出成片

导出成片节点有三个输入：

| 端口 | 说明 |
| --- | --- |
| 视频（可多条） | 按**画布上的位置**拼接：从上到下，同一高度从左到右；也可以在节点上的「时间线」里排序和剪辑（见下）。 |
| 配音（可多条） | 与某一行镜头在同一行（上下 240 像素内）的配音，从那个镜头开始播放；配音数量与镜头相同时一一对应；否则依次排列。 |
| 字幕 | 一段文本，**每行对应一个镜头**；空行表示该镜头没有字幕。行数与镜头数不同时，按总时长平均分配。 |

参数（属性面板）：

- **输出尺寸**：跟随第一个片段，或 1080p 横屏 / 竖屏 / 方形、720p。尺寸不同的片段等比缩放并补黑边，不会拉伸。
- **帧率**：24 / 25 / 30 / 60。
- **原视频声音**：与配音混合，或去掉（只保留配音）。
- **同时生成剪辑工程**：见下一节。

结果：节点里直接播放成片；属性面板可下载 MP4；「交付文件」里可下载字幕 SRT。成片内已经封装了软字幕（播放器里可开关）。编码优先 H.264 + AAC；FFmpeg 不支持 libx264 时退回 MPEG-4。

### 时间线（rc.17 起）

导出节点上的「时间线」打开片段列表：

- **顺序**：拖动行，或用 ↑ ↓ 调整。保存后节点显示「已排序」，导出按这个顺序拼接；之后新连进来的片段排在最后（按画布位置）。
- **入点 / 出点**：每段只用中间的一部分，单位是秒；留空表示从头 / 到尾。列表里显示原长和实际使用的长度。
- **整段预览**：按顺序播放每段剪好的部分（不含配音和字幕），用来检查节奏。
- 顺序和剪辑记在导出节点上（`params.order` / `params.trims`，按片段来自哪个节点记录），重新生成某个镜头后仍然有效；改了时间线，导出节点下次运行会重新合成。
- 字幕按最终顺序逐行对应；与镜头同一行的配音跟着它的镜头走。剪辑工程里每段从入点开始。
- Claude Code 等 Agent 也可以通过 `update_node` 设置这两个参数。

## 剪辑工程：在 Shotcut 里精修

勾选「同时生成剪辑工程」后再运行，「交付文件」里会多一个 `…-剪辑工程.zip`：

```
haizhu-edit/
  project.mlt      ← 用 Shotcut 打开
  clips/shot-01.mp4 …
  voice/voice-01.mp3 …
  subtitles.srt
  README.txt
```

1. 安装 [Shotcut](https://shotcut.org)（免费开源，Windows / Linux / macOS）。
2. 解压，保持文件夹结构不变（工程用相对路径引用片段）。
3. Shotcut：文件 → 打开文件 → `project.mlt`。时间线上 V1 是全部镜头（与成片顺序相同），A1、A2… 是配音（与成片中的位置相同，重叠的配音在不同音轨）。去掉原声时 V1 已静音。
4. 字幕：Shotcut 24.02 及以上，在「字幕」面板导入 `subtitles.srt`。
5. 没有图形界面时也可以用 MLT 命令行直接渲染：`melt project.mlt -consumer avformat:out.mp4`。

剪辑工程会把全部片段再复制一份，占用的空间约等于所有片段之和，因此默认不勾选。

## 常见问题

- **提示「未找到 FFmpeg」**：按上面的表安装，或设置 `HZC_FFMPEG` / `HZC_FFPROBE`，然后重启应用。
- **镜头切得太碎 / 太少**：调整切镜灵敏度或最多镜头数，再重新运行。
- **配音对不上镜头**：把配音节点挪到对应镜头的同一行，或让配音数量与镜头数量相同。
- **字幕错位**：字幕文本一行一个镜头，没有字幕的镜头留空行。
