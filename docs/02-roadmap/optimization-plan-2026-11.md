# 优化方案（2026-11）：更顺手、更灵活、更兼容的创作画布

依据：[图片 / 视频创作平台调研](../00-research/05-creative-platforms.md)（Google Flow、即梦、LibTV、可灵、Runway、Krea、Flora、LTX Studio、ComfyUI、InvokeAI 等 30 余个产品）。

## 目标

| 方向 | 要做到的事 | 衡量方式 |
| --- | --- | --- |
| **流畅** | 想到就能生成：从一句话到开始生成不超过 3 步；生成中不打断继续编辑；画布交互保持 60 帧 | 首次生成的点击次数；300 节点基准的每帧耗时（已进 CI） |
| **灵活** | 节点工作流和「一句话生成」两种用法共用同一块画布；结果可多选一、可续写、可截帧；能按组复用 | 关键流程的 E2E 覆盖 |
| **兼容** | 同一个节点在不同服务商之间切换不用改写法；服务商各自的参数（首尾帧、参考、比例、时长、扩写）由适配器翻译 | 适配器请求格式单测；真实账号试跑清单 |
| **提示词与 Skill** | 按目标模型的官方写法优化提示词；提示词 Skill 可导入、可选；导演 / 反推 / 提示词三类 Skill 走同一套导入与选择 | 优化器单测（不同模型得到不同写法指引） |

## 原则

1. **画布仍是唯一的真相**：生成栏、Agent、批量生成出来的都是画布上的普通节点，随时可以接线、改参数、重跑。
2. **先给你看，再花钱**：任何会花钱的操作在点下之前就显示次数与预估费用（按你填的单价）。
3. **自带模型与 Key 不变**：不托管模型、不计积分；提示词优化用你自己的文本模型。
4. **只借鉴交互**：不复刻任何产品的外观、文案或代码，界面沿用「石墨」设计系统。

## 版本安排

### rc.14「创作台」——想到就生成（本版）
1. **底部生成栏**：一个提示词框 + 类型（图片 / 视频）+ 模型 + 比例 + 时长 + 数量 + 参考图（自动带上画布上选中的图片，也可上传）+ 预估费用 + 生成。生成后在画布上出现对应节点并开始运行；画布正在运行时排队，不会取消正在进行的生成。Enter 生成，可收起，记住开关状态。
2. **按目标模型优化提示词**：生成栏和图片 / 视频生成节点上的「优化」按钮。用你的文本模型，按目标模型的写法改写（内置万相、Seedance、可灵、海螺、Runway、CogVideoX、通用视频；Seedream / 万相 / 可灵 / GPT Image / Gemini / FLUX 等图片写法）；接了首帧时只写运动与运镜；先显示结果，确认后替换，可撤销。
3. **提示词 Skill**：Skill 新增「提示词」用途，导入方式与反推 / 导演 Skill 相同（GitHub、压缩包、粘贴）；优化时可以选用它代替内置写法。
4. **一次多个变体**：图片 / 视频生成节点的「数量」1–4，同时生成，节点里网格显示；「选用」其中一个后只有它流向下游，其余留在版本历史里。费用预估按数量计算。
5. **接着生成 / 保存这一帧**：视频结果上的「从最后一帧接着生成」新建「尾帧图片 → 视频生成」并继承模型和参数；查看大图时「保存当前帧」成为图片节点。需要 FFmpeg。
6. **Enter 运行选中的节点**（不在输入框里时）。

### rc.15「参考与分镜」
- 视频生成的「参考图」端口，各适配器按服务商要求传（Seedance `reference_image`、MiniMax H3 参考、Runway / fal / Replicate 字段映射）。
- **主体 / 角色**：有名字的参考（多张图 + 描述 + 可选音色），在提示词里 `@名字` 引用，运行时换成对应的参考图与描述。
- **分镜表**：导演节点的结果以表格编辑（双击改格子、显示 / 隐藏列），勾选行批量展开或批量生成。
- **时间线**：把视频节点按顺序排进时间线，拖动排序、裁剪首尾、整段预览，直接交给导出节点。
- **分组**：框选后 Ctrl G 分组、整组运行、存为模板。

### rc.16「批量与一致性」
- **批量节点**：按行拆分文本、多个文件、CSV 第一列；两个批量节点「交叉」或「配对」；单次上限与费用预估。
- **宫格分镜**：九宫格 / 25 宫格分镜模板；把一张宫格图切成多个图片节点。
- **复核模式**：网格查看一个节点的全部版本，键盘翻看、打标签、选用。
- 导演 Skill 按目标视频模型写 `video_prompt`（复用 rc.14 的写法指引）。
- 服务商端的提示词扩写开关（万相 `prompt_extend`、海螺 `prompt_optimizer` 等）统一成一个节点参数。

### rc.17「Agent 与应用」
- 画布助手的方案带上每个节点的预估费用；能修改已有节点（改参数、换模型、重新连线）；「协助 / 自动」两种模式。
- **应用模式**：选几个节点参数作为输入，把一条流程变成表单式页面（适合把成熟流程交给不会接线的同事）。

### 1.0 发布收尾（不变）
Windows 真机安装测试、用真实服务商跑通完整链路、决定是否公开 Docker 镜像、打 tag（需你确认）。

## 风险与对策

| 风险 | 对策 |
| --- | --- |
| 服务商字段变化（新模型、新参数） | 适配器集中在一个文件、请求格式有单测；节点高级参数可以临时覆盖；文档写明依据与查阅日期 |
| 多变体一次花费翻倍 | 数量默认 1；费用预估按数量相乘；生成栏按钮旁直接显示 |
| 生成栏与节点两种用法分裂 | 生成栏只是「建节点 + 运行」的快捷方式，结果完全是普通节点 |
| 提示词优化改坏原意 | 先预览后替换，可撤销；保留原文；优化用的写法可以换成你自己的 Skill |
