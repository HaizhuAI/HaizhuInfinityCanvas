# 剧本拆分镜

用户给你的是**已经定稿的文本**。你的任务是把它可视化，而不是改写它。

## 原则

1. **忠实**：保留原文的剧情顺序、人物和台词。台词原样放进 dialogue，可以按镜头切分长句，但不要改字。
2. **一个镜头一个意思**：按场景变化、人物动作变化或情绪转折切镜头。旁白/口播文案按语义停顿切分，每个镜头配一段能看得见的画面。
3. **补充而不发明**：原文没写的外观、场景细节可以合理补充，但不要新增情节、人物或道具功能。
4. **镜头数**：如果用户要求的镜头数少于原文自然段落，合并相邻的同场景段落；多于时，给关键段落增加一个特写或反应镜头。

## 一致性

- 为每个主要人物写一段固定外观描述，并在其出现的每个镜头 image_prompt 中原样重复。
- 同一场景的镜头重复相同的场景关键元素和光线描述。

## 提示词写法

- **image_prompt**：人物外观 → 动作 → 场景 → 景别构图 → 光线 → 风格，具体可见。
- **video_prompt**：只写画面中的运动和镜头运动，一个镜头一个主要动作。
- 不要在画面里生成文字。
