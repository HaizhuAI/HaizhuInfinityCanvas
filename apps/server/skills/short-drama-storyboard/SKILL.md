# 短剧分镜

方法学自 [shuohao-skills](https://github.com/eternityspring/shuohao-skills) 的 novel-storyboard（Apache-2.0），按本画布的分镜格式改写：原 skill 用脚本切段、对账和拼提示词，这里由你一次写好，画布负责展开成节点。

**前提：镜头是生成出来的，多切一镜的成本几乎为零。**上限只有一个——视频模型单段生成的时长。

## 段与切

- **输出里的每个 shot 是一「段」**：一次视频生成，9–15 秒（剧情单元本来就短时可以更短，最少 3 秒），**不跨场景**——换景必开新段。
- **段内每 2–5 秒切一次**：对话用正反打，关键动作插入特写，进场先交代空间再推近。切镜写进 video_prompt 的【镜头1】【镜头2】……
- 段的总秒数 = 各切秒数之和，写进 duration（整数，不超过 15）。
- 台词要装得下：按每秒约 4.5 个字估算，一切的台词念不完就再切。

## 字段怎么写

| 字段 | 写什么 |
| --- | --- |
| title | 段的小标题：场景 + 事件 |
| visual | 这一段发生什么，中文一两句 |
| camera | 段内各切的景别与运镜，用「 / 」分开，例如「全景 跟拍 / 近景 固定镜头 / 特写 推镜」 |
| dialogue | 这一段的台词，逐字照抄原文，说话人写在前面（「老周：上船喽——」）；没有台词写空字符串 |
| duration | 段内各切秒数之和 |
| image_prompt | **第一切的分镜图提示词（首帧）**：中文；中文景别词写进去；**直呼角色名并写成 @名字**（画布会把主体的描述和参考图一起带上，名字以「设定」里给出的为准）；写清此刻的位置状态、动作瞬间、光线与氛围；不写画风词 |
| video_prompt | 按 Seedance 官方结构写，见下 |

video_prompt 的结构（每一行只在有内容时出现；台词行例外，没有台词也写 `台词：{}`）：

```
【人物关系与构图逻辑】
开场那一瞬谁在画面左、谁在右、面朝哪、相距多远（厘米或步数）

【镜头1】
焦距：50mm 标准，中浅景深
机位：年轻女子 + 平视正面
构图：三分法
运镜：缓慢推镜
景别：中景
画面：这几秒发生什么（运镜 → 主体动作与表情 → 位置或空间变化）
台词：{逐字台词}
视线落点：对方面部
焦点：锁定年轻女子上半身
稳定性：稳定
音效：被褥摩擦声

【镜头2】
……

<环境声、动作声、非语言人声，不复述台词>
（配乐的配器与速度；没有配乐就省略这一行）

【约束】
1. 保持无字幕，避免生成任何文字或字幕
2. 视频全程禁止出现外形、着装、配饰完全一致的人物（段内有两人及以上同框时才写这一条）
```

要用 MiniMax H3 出片时，video_prompt 改用 references/h3-prompt.md 的三段结构（整条英文，台词放进 `<d>[Chinese] …</d>`）。

## 写法要点（完整版见 references/shot-writing.md）

1. **一切一个运镜**，写成动作句（「镜头小幅缓推向掐白的指节」），可加幅度与速度。
2. **动作要在这几秒内做得完**：肢体细化 + 程度量化（缓慢抬手、微微低头），优先低缓连续的小动作，写出前后动作的承接；情绪写成身体细节，不写「很悲伤」。
3. **人物此刻在哪要和首帧一致**：首帧钉的是这一段开始的那一瞬。
4. **台词逐字保留**，一个标点都不改；身份、语气、是否画外音写在台词外面（画外音写「以画外音说{……}」）。
5. **视频提示词不写角色姓名**，用通用身份（「一名铁灰袍中年男子」）——这是 Seedance 与 H3 官方规范；首帧提示词恰好相反，要写 @名字。
6. **构图要量化**：焦距与景深、机位、构图法、视线落点、焦点、稳定性每切都写；段开头写人物关系与构图逻辑。
7. **声音分三层**：台词进 `{}`；环境与动作声进 `<>`；配乐进 `（）`。声景也是动作指令，画面改了声景一起改。
8. **不写**：剧本没有的人物、道具、动作、台词和画面文字；画风词（电影感、色调名）——画风由画布统一附加；秒数、时间码、镜头编号以外的标记。
